Powerhouse tri-engine ghost browser skill for AI agents. Combines Ghost Graph LLM extraction pipelines, FastMCP undetectable browser automation, and the ultra-lightweight Ghost Core native CDP micro-engine.

1

Ghost Graph Pipelines

  • Smart Scraper: Single-pass extraction of structured JSON or Markdown.
  • Search Graph: Multi-source web search query synthesis.
  • Multi-Model: Gemini, Claude, OpenAI, Groq, and local Ollama.
  • Zero-Cost: Local model extraction without third-party subscriptions.
python scripts/scrape.py --url <URL> --json
2

FastMCP Stealth Automation

  • Anti-Detection: Defeats Cloudflare & Queue-It via nodriver heuristics.
  • 97-Tool Suite: Navigation, human typing, clicks, and tab control.
  • Pixel-Accurate: Clones DOM elements with computed CSS styles.
  • Dynamic Hooks: Injects Python hooks to intercept/rewrite traffic.
python src/server.py --minimal
3

Ghost Core Micro-CDP

  • 30MB Footprint: Ultra-lean memory footprint (vs 250MB+ Chromium).
  • Sub-100ms Speed: Instant startup for high-concurrency loops.
  • Hardware Spoof: Randomized WebGL, Canvas noise, and Audio jitter.
  • CDP WebSocket: Drop-in ws://127.0.0.1:9222 for Playwright scripts.
python scripts/ghost_core.py --serve
