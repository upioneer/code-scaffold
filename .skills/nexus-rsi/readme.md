## Description

The Nexus Recursive Self-Improvement Engine is Code Scaffold's autonomous agent evolution and predictive world modeling framework. By simulating prospective actions in latent state embeddings before execution, filtering synthetic experience trajectories, and coordinating iterative policy and world model co-evolution, Nexus unlocks safe and bounded recursive self-improvement across code repair, GUI automation, and complex multi-step reasoning domains.

## Capabilities & Use Cases

* **Joint Embedding Predictive World Models**: Simulates prospective environment transitions and action sequences in abstract latent space to forecast outcomes without high-cost rollouts.
* **Recursive Self-Improvement (RSI) Dual Loop**: Coordinates synchronized updates between agent operational policies and predictive world models, filtering high-value synthetic trajectories.
* **Counterfactual Trajectory Simulation**: Evaluates alternative candidate actions against predicted world states to optimize action selection before live tool execution.
* **Multi-Domain Task Adapters**: Out-of-the-box adapters for autonomous code repair and debugging, GUI interaction planning, API choreography, and scientific computation.
* **Bounded Evolution & Rollback Checkpoints**: Strict convergence bounds, reward drift prevention, counterfactual validation, and state rollback checkpoints to ensure alignment and safety.
* **Headless RSI CLI Bridge**: Lightweight scripting suite to benchmark policy iterations, measure capability deltas, and export optimized agent parameters.

## Usage

Invoke this skill when an agent is asked to:
* Apply recursive self-improvement loops to optimize agent performance on complex repetitive tasks
* Simulate and evaluate candidate action plans using predictive world models before executing live commands
* Generate, score, and filter synthetic reasoning trajectories for self-supervised policy enhancement
* Solve iterative code repair or system debugging challenges through simulated trial-and-error
* Establish safe, checkpointed evolution boundaries for autonomous workflows
