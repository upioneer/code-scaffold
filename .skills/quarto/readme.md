# Quarto Scientific Publishing

**Version:** 1
**Target:** `.skills/quarto`

## Description
A comprehensive automation skill for Quarto, the open source scientific and technical publishing system built on Pandoc. It empowers agents to dynamically weave together narrative text and code to produce elegantly formatted HTML, PDF, Word, ePub, Reveal.js slides, and interactive dashboards.

## Capabilities & Use Cases
* **Polyglot Code Execution** : Seamlessly orchestrates Python, R, Julia, and Observable JS within a single markdown document to generate dynamic computational narratives.
* **Complex Artifact Generation** : Compiles structured markdown into beautiful interactive websites, academic books, scientific manuscripts, and data dashboards.
* **Automated Data Pipelines** : Enables agents to act as autonomous data scientists by generating analytical notebooks (`.qmd`), executing the embedded computational cells, and exporting the final rendered artifacts for the user.
* **Curated CI/CD Integration** : Bundled with zero configuration GitHub Actions workflow templates to instantly deploy Quarto websites and books to GitHub Pages.
* **Observable JS Dashboards** : Scaffolds interactive client side data dashboards without requiring a backend server, utilizing the Quarto dashboard architecture.
* **Semantic Cross Referencing** : Automates the generation of complex academic cross references, citations, footnotes, and mathematical equations (via LaTeX/MathJax).

## Usage
Activate this skill when an agent needs to generate high fidelity data reports, build scientific documentation websites, scaffold interactive data dashboards, or publish computational notebooks using the Quarto CLI.
