## Description
Skeleton Performance Studio is an industrial grade frontend optimization skill engineered to eliminate perceived loading latency and guarantee zero Cumulative Layout Shift (CLS: 0.00). By reserving exact spatial geometry before asynchronous payloads resolve, it transforms disruptive visual popping into smooth, ambient transitions across web applications.

## Capabilities & Use Cases
* **Zero Cumulative Layout Shift (CLS: 0.00)**: Guarantees strict layout reservation across asynchronous hydration boundaries, ensuring that incoming text blocks, images, and user avatars never cause unexpected layout shifts or lower Google Core Web Vitals scores.
* **Perceived Performance Acceleration**: Implements proven visual placeholder techniques that reduce perceived page load latency by 30% to 40% compared to traditional spinner wheels and blank states.
* **Pure CSS Hardware-Accelerated Shimmer Engine**: Zero-runtime CSS shimmer animations leveraging GPU-composited transform sweeps (`translateX`) and ambient pulse breathing cadences with zero JavaScript bundle overhead.
* **Staggered Dimensional Geometry**: Realistic text paragraph skeletons with natural multi-line termination cadences (100%, 92%, 65%) that emulate human linguistic flow rather than artificial solid blocks.
* **Aspect-Ratio Media Locking**: Pre-allocated aspect-ratio containers (16:9 widescreen, 1:1 square, 4:3 standard) for video players, hero images, and thumbnail cards that prevent vertical viewport jumping.
* **React 19 & Next.js App Router Suspense Streaming**: Complete reference architecture for Next.js App Router streaming (`loading.tsx`), granular React Suspense fallback boundaries, and Server Component integration.
* **Tailwind CSS Utility Integration**: Drop-in utility class compositions and reusable Tailwind CSS skeleton primitives matching modern UI design systems.
* **Accessibility (a11y) Compliant**: Baked-in `aria-busy="true"`, `aria-live="polite"`, `role="status"` containers, screen reader announcements, and automated `prefers-reduced-motion` fallbacks.
* **Spectral Dark Mode Palette**: Styled in Code Scaffold dark theme aesthetics featuring subtle Spectral Cyan (`#00f0ff`) highlights over deep dark slate backgrounds (`#06090e`).
* **Authoritative Architectural Contract Card**: Standardized contract card presenting CLI installation syntax, programmatic import examples, YAML schemas, and domain constraints on code-scaffold.com.

## Usage
AI agents and developers invoke the Skeleton Performance Studio to build, scaffold, and optimize loading screens across any web stack:

* Next.js App Router route streaming: Scaffolds `app/**/loading.tsx` with zero-CLS page skeletons.
* Component fallback generation: Creates companion skeleton variants for cards, avatars, tables, and media grids.
* Pure CSS injection: Embeds hardware-accelerated shimmer keyframes into stylesheets with zero dependencies.
* Ad-hoc CLI installation: `code-scaffold skills install skeleton`
