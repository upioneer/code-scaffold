        Hosted MCP Server Orchestration
        https://app.quiver.ai/mcp
      

      

        Quiver AI exposes a hosted Model Context Protocol (MCP) server over Streamable HTTP with OAuth. Connected agents use structured tool loops to query models, dispatch background tasks, poll lifecycles, and extract production vector assets.
      


      

        

          
1

          

            
Catalog Handshake : list_models

            
The agent discovers available Arrow foundation models and validates organizational authorization before invoking creation endpoints.

          

        

        

          
2

          

            
Task Dispatch : create_generation / create_vectorization

            
Agent provides natural language prompt or image reference. The MCP server returns a queued taskId and future creationIds.

          

        

        

          
3

          

            
Asynchronous Polling : get_task

            
Agent checks the task lifecycle until the status transitions to completed. Never displays preview snapshots as final deliverables.

          

        

        

          
4

          

            
Asset Extraction : get_creation_content

            
Agent extracts clean raw SVG code. When includePng: true is provided, an inline PNG preview is included for instant visual chat rendering.
