## Discovery & Ad-Hoc CLI Installation

Every skill in this registry includes a standardized `skill-manifest.json` distribution payload. You can discover, inspect, and install any individual skill ad-hoc into your workspace:

```bash
# Search skills by keyword or domain
code-scaffold skills search <keyword>

# Install a skill into your current repository
code-scaffold skills install <skill-name>
```
