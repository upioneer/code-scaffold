# Privacy Policy Generator

**Label:** Privacy Policy Generator
**Description:** Generates a customizable privacy policy tailored to the project (website/app) with optional Google Analytics integration.
**Version:** 4

## Usage

This skill automates the creation of a privacy policy for a website or application. When invoked, it will prompt the user with multiple-choice questions to gather necessary context (e.g., platform, business/individual, country, effective date, and Google Analytics inclusion).

## Capabilities & Use Cases
* Generates a fully compliant privacy policy template.
* Interactive multi-choice prompting for the user.
* Injects Google Analytics clauses if selected.
* Mindful of platform differences (Website vs App).
* Analyzes app/website design to recommend optimal link placement.
* Offers multiple UI display formats (Modal, Slug, Inline).
