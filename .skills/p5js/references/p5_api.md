# p5.js Reference

## Core Functions
*   `setup()`: Called once when the program starts. Used to define initial environment properties (canvas size, background).
*   `draw()`: Called continuously after `setup()`. Used for animation and interactivity.

## Common API
*   `createCanvas(w, h)`: Sets the size of the drawing area.
*   `background(r, g, b)`: Sets the background color.
*   `fill(c)` / `stroke(c)`: Sets color for shapes and lines.
*   `ellipse(x, y, w, h)` / `rect(x, y, w, h)`: Draws basic shapes.
*   `mouseX` / `mouseY`: Current mouse coordinates.
