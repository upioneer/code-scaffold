# p5.js Creative Coding

**Version:** 2
**Target:** `.skills/p5js`

## Description
Creative coding and visual animations using the p5.js library.

## Capabilities & Use Cases
* **Creative Coding & Generative Art**: Rapidly build interactive visual experiences, custom animations, and generative artwork directly in a native web environment.
* **Zero-Configuration Scaffolding**: Instantly provision an optimized baseline project featuring an `index.html` boilerplate configured with CDN-linked p5.js and p5.sound libraries.
* **Structured Animation Loop Architecture**: Implements standard p5.js state management patterns out of the box, cleanly separating `setup()` initialization logic from the 60FPS `draw()` update loop.
* **Interactive Event Handling**: Includes foundational implementations for mapping real-time user inputs (such as cursor coordinates via `mouseX`/`mouseY`) to dynamic visual outputs.
* **Standalone or Server Execution**: Flexibly execute simple sketches directly in the browser via `file://` or seamlessly scale up to local development servers (e.g., `live-server`) for advanced asset loading requirements.
