**Version:** 4
**Target:** `.skills/ratatui`
**Category:** Frontend & UI Design

## Description
Build Terminal User Interfaces (TUI) using Ratatui in Rust.

## Capabilities & Use Cases
* **Crossterm Backend Integration**: Seamlessly interfaces with the `crossterm` backend for highly cross-platform, efficient, and robust terminal rendering and event handling.
* **Elm Architecture (MVU)**: Enforces the Model-View-Update (Elm) architecture to maintain a clear separation of concerns, ensuring maintainable, state-driven user interfaces.
* **Responsive Layouts & Constraints**: Utilizes Ratatui's native Layouts and Constraints framework to build deeply responsive designs that automatically adapt to terminal resizing events.
* **Data-Driven Non-Blocking Rendering**: Implements rendering loops that remain entirely non-blocking and data-driven, guaranteeing ultra-smooth user experiences even during heavy computation cycles.
* **Direct Documentation References**: Embeds immediate reference links to core Ratatui documentation and tutorials, accelerating developer workflows.
