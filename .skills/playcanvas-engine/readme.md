## Description
Modular 3D/2D game engine for the web supporting WebGL and WebGPU.

## Capabilities & Use Cases
* **Automated Project Scaffolding**: Instantly initialize new standalone, engine-only PlayCanvas environments using the official Node.js CLI generator architecture.
* **Pre-Configured Scene Boilerplates**: Inject robust, ready-to-run 3D scene templates complete with instantiated Applications, Cameras (with clear colors), and directional Lights.
* **Strict Type Intelligence**: Explicitly forces agents to leverage `playcanvas.d.ts` for deep API introspection, ensuring correct WebGL/WebGPU implementation paths.
* **Component-Driven Scripting**: Provides exact syntactical templates for dynamic logic attachment (`app.systems.script.addComponent`) for programmatic interactivity.
* **Asynchronous Asset Pipeline**: Outlines standardized implementations for asynchronous resource handling (`app.assets.load`) directly within the engine loop.
