## Description
Generates Marp presentation slides from Markdown

## Capabilities & Use Cases
* **Presentation Generation** : Transform structured content or raw outlines into professional robust slide decks using the Marp Markdown ecosystem
* **Theme Integration** : Seamlessly apply built in Marp themes such as default, gaia, or uncover via automated Markdown frontmatter injection
* **Slide Formatting Automation** : Segment content systematically into logical slide breaks utilizing horizontal rulers while ensuring strict newline compliance
* **Image Manipulation** : Inject Marp specific syntax for precise image resizing and expansive aesthetic background images
* **Interactive Elements** : Generate fragmented bullet lists and segmented elements natively compatible with the Marp CLI parser
* **Directive Configuration** : Implement precise global and local directives to intricately control critical slide behavior like pagination, headers, footers, and aspect ratio
* **Artifact Compilation** : Produce a pristine Marp compatible Markdown file optimized for instantaneous conversion to PDF, HTML, or PowerPoint via the Marp CLI
