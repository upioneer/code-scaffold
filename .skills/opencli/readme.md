# OpenCLI

**Version:** 2
**Target:** `.skills/opencli`

## Description
Bridge websites and the CLI for structured data extraction and browser automation

## Capabilities & Use Cases
* **Intelligent Site Discovery**: Dynamically query and verify supported websites, adapters, and available commands before executing workflows to ensure operational reliability.
* **Structured Data Extraction**: Seamlessly execute domain-specific searches (e.g., Google) or generic DOM target extractions using CSS selectors, returning strictly formatted JSON envelopes.
* **Experimental Browser Automation**: Bypass adapter limitations with direct browser instantiation and manipulation, including page inspection and executing sequenced interaction macros.
* **Agent-Optimized Workflows**: Architected specifically for autonomous AI agents, prioritizing native adapters over raw browser automation for stability and speed.
* **Adapter Authoring Methodology**: Use built-in reconnaissance tools and primitives to safely explore unknown sites and author robust new data adapters on the fly.
* **Node.js Integration (`run.js`)**: Deep programmable integration with seamless dependency management and standard stream (stdin/args) ingestion for custom automation pipelines.
