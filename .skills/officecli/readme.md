## Description
OfficeCLI is the first and best Office suite purpose-built for AI agents to read, edit, and automate Word, Excel, and PowerPoint files. Free, open-source, single binary, no Office installation required.

## Capabilities & Use Cases
* **Universal Office Automation:** Edit `.docx`, `.xlsx`, and `.pptx` files entirely via CLI commands without any Microsoft Office installation or runtime dependencies.
* **JSON Structured Interrogation:** Retrieve structured JSON for any element in a document (e.g., getting the precise coordinates of a textbox or the values in a spreadsheet).
* **Live HTML Previews:** Renders Office documents into high-fidelity HTML or PNG files to close the visual feedback loop.
* **Complex Data Manipulation:** Perform multi-key sorts, apply conditional formatting, execute 350+ built-in formula functions, and generate charts directly from headless environments.

## Usage
Agents can install the OfficeCLI binary, build presentations programmatically via sequential shell commands, and read Excel/Word configurations directly into standard JSON objects for contextual processing.
