🚀 Welcome to XCross

Step 1 of 5

Step 1: Build iOS Apps Anywhere

XCross lets you write and compile iOS apps on Linux, Windows WSL, and macOS without installing Xcode. Standard Swift Package Manager packages are cross-compiled directly into native iOS arm64 Mach-O binaries.

$ node .skills/xcross/scripts/xcross_bridge.mjs doctor

Run the diagnostic tool anytime to verify your Swift toolchain and USB connection daemons.

Step 2: Apple Developer Credentials

Physical iOS devices require cryptographic code signatures. XCross integrates with the App Store Connect API to generate development certificates and provisioning profiles automatically.

export APPLE_KEY_ID="ABC123XYZ"
export APPLE_ISSUER_ID="57246542-..."
export APPLE_PRIVATE_KEY_PATH="~/.keys/AuthKey.p8"

Configure these variables once, and XCross handles signing without manual portal navigation.

Step 3: Lightweight Project Anatomy

Instead of heavy .xcodeproj directories, an XCross project consists of standard files:

SolarTracker/
├── Package.swift # SwiftPM manifest
├── xcross.yml # Bundle ID, icons, entitlements
└── Sources/ # SwiftUI App.swift & ContentView.swift

Scaffold a new project in one command: xcross init MyApp

Step 4: Connecting Physical Hardware

Plug in your iPhone or iPad via USB cable. XCross uses usbmuxd to talk directly to the iOS kernel.

* Unlock your iPhone and tap "Trust This Computer"
* On iOS 16+, enable Developer Mode in Settings
* On Windows WSL2: usbipd attach --wsl --busid <ID>

Verify with xcross devices to view connected hardware.

Step 5: One-Command Live Deployment

Run the development loop to cross-compile SwiftPM sources, compile asset catalogs, sign the binary, and deploy straight to your iPhone:

$ xtool dev

🎉 You are ready to develop iOS apps with absolute freedom from heavy macOS workstations!
