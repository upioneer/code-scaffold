# Tasty

**Version:** 2
**Target:** `.skills/tasty`

## Description
Tasty is Code Scaffold's bespoke, native anti-slop frontend orchestration engine. It acts as a strict cognitive enforcer that overrides default LLM aesthetic biases, ensuring AI agents ship premium, high-fidelity user interfaces instead of generic templates.

## Capabilities & Use Cases
* **Aesthetic Trajectory Parsing:** Automatically interprets user intent from plain-text briefs (e.g., minimalist, public-sector, editorial, brutalist) and translates them into actionable frontend methodologies.
* **Command Vocabulary:** Provides a suite of direct agent commands (`/tasty init`, `/tasty polish`, `/tasty bolder`, `/tasty distill`, etc.) to procedurally refine, audit, and inject aesthetic variations into existing codebases.
* **Component-Level Discipline:** Imposes strict layout rules such as prohibiting horizontal nav overflow, capping hero text limits, and dynamically restructuring data grids based on content volume.
* **Slop Elimination:** Forbids notorious AI artifacts such as unmotivated purple gradients, fake-precise placeholder numbers, non-accessible contrast palettes, mixed-font emphasis, nested card crutches, and overused fonts like Inter.
* **Headless Visual Auditing:** Tightly integrated with the Playwright automation framework to enable AI agents to natively capture, review, and mathematically verify rendered DOM structures.
* **Autonomous Asset Provisioning:** Forces agents to mechanically generate real placeholder assets or script dynamic image queries rather than abandoning empty DOM elements.
* **Git-Native Safe Overhauls:** Restricts agents from executing destructive styling sweeping changes on main by mandating isolated staging branches for visual review.

## Usage
Agents should read and abide by `SKILL.md` when acting in a frontend or web-development capacity. The engine's principles should be applied silently during DOM generation and CSS architecture scaffolding. Users can invoke specific `/tasty` commands in prompts to steer agent output.
