Workflows

  • Scout first: probe ADB, SDB, webOS, Cast, and JointSpace surfaces with tv_scout.py
  • Android TV / Google TV: record, plan, debloat, swap launcher, verify, restore path included
  • Fire TV: choice sheet cleanup plus DNS filtering where the launcher resists
  • LG webOS: home helper without root, full control plane with root
  • Samsung Tizen: exact firmware research with honest evidence labels
  • Automation: ADB, SDB, webOS sockets, DIAL, Cast, DLNA, MQTT, Wake on LAN

Helper Scripts

  • scripts/tv_scout.py LAN debug surface scout with built in self test
  • scripts/debloat_plan.py Tiered reversible debloat planner with built in self test
  • data/package_tiers.json Starter disable tiers with verified stock packages

Safety Rails

  • Home guard: a replacement must answer HOME before stock is silenced
  • Record first: every plan ships with its restore script
  • LAN only: no debug bridge or dashboard ever leaves the home network
