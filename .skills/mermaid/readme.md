# Mermaid

**Version:** 2
**Target:** `.skills/mermaid`

## Description
Mermaid diagram creation and rendering

## Capabilities & Use Cases
* **Visual Diagram Generation** : Design and generate professional visual diagrams using the comprehensive text based Mermaid syntax framework
* **Broad Diagram Support** : Create complex flowcharts sequence diagrams class diagrams state diagrams entity relationship diagrams mindmaps and custom layouts natively
* **Depth Level Assessment** : Assess diagram intent dynamically to generate either high level abstract architectures or highly technical precise component flows
* **Thematic Configuration** : Apply robust theming and precise rendering configuration such as ELK layout algorithms utilizing standard YAML frontmatter and init directives
* **CLI Integration** : Render SVG or PNG graphic artifacts automatically using the robust mermaid cli node wrapper
* **Code Embedding** : Embed native Mermaid syntax directly into Markdown code blocks or generate dedicated standalone mmd files for external integration pipelines
* **Syntax Verification** : Ensure robust syntax generation actively avoiding special characters and enforcing precise keyword structures to prevent rendering and parsing failures
