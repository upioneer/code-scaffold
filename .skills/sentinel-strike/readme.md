## Description

The Sentinel Strike Autonomous Red-Team Matrix is Code Scaffold's dedicated autonomous security assessment and continuous penetration testing engine. It coordinates a specialized multi-agent mesh across reconnaissance, proof-of-concept synthesis, sandboxed execution, and dual-memory attack surface mapping to discover, validate, and verify remediations for mission-critical security postures.

## Capabilities & Use Cases

* **Autonomous Multi-Agent Red-Team Mesh**: Orchestrates specialized agent personas (Scout, Synthesizer, Executor, Auditor) to execute end-to-end security posture assessments with verifiable checkpoints.
* **Dual-Memory Attack Surface Mapping**: Constructs a persistent knowledge graph of assets, relationships, trust boundaries, and discovered vectors alongside high-density vector trajectory memory.
* **Ephemeral Sandboxed Container Isolation**: Executes diagnostic tooling and exploit verification inside strictly isolated, network-segmented containerized environments to prevent unintentional lateral movement.
* **Defensive Verification & Remediation Loop**: Validates security patches and configuration hardening by replaying confirmed attack vectors to ensure total vulnerability closure.
* **Scope Whitelisting & Governance Guardrails**: Strict target authorization boundaries, non-destructive audit configurations, and auditable transaction logging.
* **Headless Security CLI Bridge**: Programmatic command-line interface for CI/CD pipeline integration, scheduled penetration sweeps, and automated compliance artifact generation.

## Usage

Invoke this skill when an agent is asked to:
* Perform authorized autonomous penetration testing or red-team simulation against target environments
* Map external or internal attack surfaces into persistent knowledge graph representations
* Validate vulnerability remediations and security patches through safe, sandboxed reproduction
* Run automated multi-agent vulnerability discovery pipelines within isolated Docker containers
* Generate comprehensive security posture audits and executive compliance reports
