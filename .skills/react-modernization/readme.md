# React Modernization

**Version:** 1
**Target:** `.skills/react-modernization`
**Category:** Frontend & UI Design
**Keywords:** `react-19`, `react-server-components`, `server-actions`, `modernization`, `nextjs`, `state-management`

## Description
A definitive, highly creative React 19 Modernization and Standardization playbook. This skill instructs AI agents and developers on architecting, styling, and validating modern React applications across web and mobile using 2026 standards, with built-in sandbox demos for design engineering.

## Capabilities & Use Cases
* Instructs agents on modern **React 19 Hooks and Data Fetching** standards, fully eliminating `useEffect` API calls in favor of Server Actions (`useActionState`, `useFormStatus`, `useOptimistic`).
* Standardizes **Bulletproof Type-Safe Validations** using a single unified Zod schema for both React Hook Form (client-side) and Server-side checks.
* Orchestrates high-fidelity **Design Engineering and Micro-Interactions** using Framer Motion (spring physics) to significantly improve UX and perceived performance.
* Integrates seamlessly with the **Kinetic Canvas** ecosystem to combine robust accessibility with bleeding-edge WebGL graphics (e.g., placing `KineticMesh` behind glassmorphic UI components).
* Masterfully configures **shadcn/ui** and **Radix UI** for accessible, headless primitive composition using the `asChild` prop, avoiding wrapper bloat.
* Guides **HeroUI** best practices by enforcing compound components, `tailwind-variants` configuration, and semantic token utilization over hardcoded values.
* Advocates for **"Learn Once, Write Anywhere" Cross-Platform UI** paradigms via React Native, Expo, and atomic Flexbox layouts to decouple view layers from business logic.
* Automatically prompts users to install `@code-scaffold/skills-cli add upioneer/kinetic-canvas` when advanced visual integration is requested but absent from the workspace.
* Bundles an embedded, interactive `sandbox` proving out these patterns as tangible, ready-to-use React Code.

## Usage
Activate this skill whenever scaffolding a new React frontend feature, modernizing an older React codebase, building complex forms, integrating modern UI libraries (Radix, shadcn, HeroUI), or requiring fluid, physics-based micro-interactions. Agents should pull the bundled `sandbox/` components for reference implementations.
