**Version:** 2

## Description
This skill provides the intelligence and instructions needed to build, configure, and customize Reveal.js presentations.

## Capabilities & Use Cases
* **Comprehensive Installation & Setup Workflows**: Supports multiple architectural integration paths, including lightweight static HTML structures, complete repository clones with build tools, and modern package manager (npm/yarn) integrations for React/Vue apps.
* **Core Markup & Layout Architecture**: Provides deep instructions for strict HTML structure, multi-dimensional slide navigation (vertical stacks), native Markdown content ingestion, and responsive layout classes (`r-fit-text`, `r-stretch`, `r-stack`).
* **Advanced Animations & Transitions**: Controls granular animations using `data-auto-animate` mapping, native transitions (fade, zoom, convex), and sequential element reveal capabilities via `fragment` classes.
* **Plugin Ecosystem Integration**: Natively handles and configures critical core plugins including `RevealMarkdown`, `RevealHighlight` (syntax highlighting), and `RevealNotes` (speaker view integrations).
* **JavaScript API & Customization**: Demonstrates deep programmatic control via the `Reveal.initialize` API, dynamic slide navigation, and global presentation event listeners.
* **Production Export Workflows**: Outlines exact methodologies for producing pristine PDF exports from presentations, including margin and background graphic configurations.

## Usage
Agents should invoke this skill when a user requests to create, modify, or export a Reveal.js presentation. The skill acts as a comprehensive knowledge base for proper DOM structure, API usage, and configuration best practices.
