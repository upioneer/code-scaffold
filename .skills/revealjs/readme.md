# Reveal.js

**Version:** 1
**Target:** `.skills/revealjs`

## Description
This skill provides the intelligence and instructions needed to build, configure, and customize Reveal.js presentations.

## Capabilities & Use Cases
* Scaffold Reveal.js presentations from scratch using basic or full setups
* Configure slide layouts, auto animations, and dynamic transitions
* Integrate essential plugins like Markdown, Highlight, and Speaker Notes
* Automate the PDF export workflow and manage speaker views
* Troubleshoot common limitations like media autoplay and markdown indentation

## Usage
Agents should invoke this skill when a user requests to create, modify, or export a Reveal.js presentation. The skill acts as a comprehensive knowledge base for proper DOM structure, API usage, and configuration best practices.
