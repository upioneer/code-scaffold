Critical Engineering Rules
Rule 1
Integer Disk Sizing
pct create parses "4G" as a logical volume name. Always strip non-numeric chars with tr -dc '0-9' before --rootfs.
Rule 2
Bootstrap Isolation
Debian 12 minimal has no curl. Fetch on host, pct push, pct exec, clean up. Never curl-pipe inside the container.
Rule 3
V8 Heap Ceiling
npm run build crashes (exit 134) with under 2048MB RAM. Set NODE_OPTIONS="--max-old-space-size=1536" before every build.
Rule 4
Pipe-Safe Dialogs
curl-pipe stdin is not a TTY. Run exec < /dev/tty before whiptail. Always provide read -r -p fallback.
Rule 5
Active Health Verification
Poll systemctl is-active 15s, then HTTP health endpoint 20s. On failure, dump journalctl -n 50 immediately.
Rule 6
Idempotent Updates
Every install creates /opt/<app>/update.sh linked to /usr/local/bin/update-<app>. Re-runnable without side effects.
