# Walkthrough v3.1.0

## Overview
This version adds two significant creative and educational skills to the library: **p5.js** and **Manim**. These payloads enable rapid bootstrapping of interactive visual art and mathematical animations.

## New Features

### p5.js Creative Coding Skill
Provides a boilerplate for web-based interactive sketches.
*   **Assets:** Standard `index.html` (with CDN links) and a responsive `sketch.js` template.
*   **Documentation:** Core API reference and getting started guide.

### Manim Math Animations Skill
Provides a foundation for programmatic mathematical animations.
*   **Assets:** A Python boilerplate `scene.py` with a "Hello World" transformation example.
*   **Documentation:** CLI command reference and dependency guide (FFmpeg, LaTeX).

## Maintenance Updates
*   **Manifest Sync:** Root `manifest.json` updated to version 3.1.0.
*   **Skill Metadata:** Created `meta.json` files for both `p5js` and `manim`.
*   **Global Documentation:** Updated project README and `.skills/README.md`.
