# Code Scaffold v6.1.1

## Overview
This patch update refines the user interface of the Code Scaffold TUI, specifically focusing on the onboarding workflow and theme engine discoverability.

* **Contextual Instructions**: Injected the custom theme engine launch instruction directly into the Summary Pane text block during the "Step 1: Deployment Target" workflow phase, ensuring users only see the command when it's most contextually relevant.
