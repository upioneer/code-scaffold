# Code Scaffold v7.3.3

* **skills-cli (v1.0.12):** Implemented a bulletproof 3-phase extraction engine (Sparse Clone -> Shallow Clone -> cURL Tarball) to bypass automated agent Git restrictions, and added network timeouts to prevent hanging.
