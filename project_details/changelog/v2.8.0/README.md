# Version 2.8.0

## Release Summary
This version introduces the **OpenCLI Bridge** skill, enabling seamless data extraction and automation between websites and the CLI.

## Key Changes
* **New Skill: OpenCLI**:
    * Integrated a bridge for structured data extraction from supported websites (Google, GitHub, etc.).
    * Added a universal executor (`run.js`) for running OpenCLI commands via `npx`.
    * Included comprehensive discovery and execution patterns in `SKILL.md`.
* **Manifest & Documentation**:
    * Incremented the root `manifest.json` version to `2.8.0`.
    * Updated the root `README.md` and `.skills/README.md` to reflect the new OpenCLI capability.
