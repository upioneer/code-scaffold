# Version 4.6.0

## Feature Additions
* **AI Systems Engineer Persona**: Introduced a brand new `AI Systems Engineer` agent persona into the core scaffold TUI. This persona is explicitly scoped for modern AI development, including LLMs (hosted/local), multimodal generation architectures (ComfyUI), top-tier APIs (Claude, Gemini, Grok, ChatGPT), OpenRouter routing, comprehensive AI CLI tools (Antigravity, Claude Code), and advanced RAG/Agentic frameworks (LangGraph, PixelRAG, Dify, LlamaIndex).
* **AI Quality of Life Companions**: Implemented automated companion selection for the `AI Systems Engineer` persona. Selecting this persona now automatically provisions the `mcp-generator` (for Model Context Protocol integration) and `trackio` (for ML experiment tracking) skills.
