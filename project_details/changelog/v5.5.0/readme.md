# Version 5.5.0

## Core UX Enhancements
* **Modal Vertical Scrolling:** Successfully introduced a full vertical scrolling mechanism into the TrueColor Welcome modal. Users running Code Scaffold on constrained or low-resolution terminal window profiles can now utilize `[Up]` and `[Down]` traversal keys. This seamlessly manipulates the native `Paragraph` offset to scroll through hidden text without shattering or distorting the ANSI block elements, ensuring execution instructions (such as injecting PATH variables) are fully accessible under any configuration.
* **Responsive Logo Tiers:** Re-engineered the UI rendering payload to evaluate the raw terminal width natively within the draw loop. The interface dynamically cascades between the massive ANSI art, a structurally aligned `Mini Logo` (generated using identical FIGlet fonts), or completely hides the logo payload to strictly prioritize instructional text on severely constrained screens.
* **Smart PATH Detection:** Upgraded the Welcome modal's environmental awareness to automatically query the user's `PATH` variable at runtime. If the CLI is already successfully installed in the path, it intelligently collapses the redundant Windows `[P]` injection instructions in favor of a clean verification badge.
* **Native Changelog Injection:** Architected a build-time execution script (`build.rs`) that statically links the newest version's release notes directly into the compiled payload. The `prefs.json` boolean flag has been overhauled to track the exact `CARGO_PKG_VERSION` string, guaranteeing the Welcome modal is automatically surfaced to users immediately following an application update to broadcast the latest changelog.
