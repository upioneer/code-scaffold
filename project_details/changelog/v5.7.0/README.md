# v5.7.0

## Changelog
* **Custom Theme Engine:** Rebuilt the internal `Theme` structure to utilize heap-allocated `String` representations, breaking free from hardcoded stock limits and allowing true extensibility.
* **OEM + User Customizations:** Fused the built-in stock themes with a persistent `prefs.json` custom theme injection at boot, allowing developers to craft their own aesthetics without compromising the core OEM defaults.
* **Sequential Theme Wizard:** Introduced a robust, highly polished interactive UI wizard for theme creation directly from the application via the `[Shift+E]` hotkey.
* **Intelligent Contrast Guards:** Shipped an internal geometric distance algorithm to calculate RGB euclidean deltas on-the-fly, enforcing a strict minimum contrast ratio to prevent users from rendering the UI illegible.
* **Auto-Derivation Algorithm:** Implemented automatic 3-color synthesis (secondary and accent derivation based on primary color luminosity), scaling complexity down to a simple 3-input flow while retaining the advanced 5-input capability natively out of the box via `[Tab]`.
* **Dynamic Content Modal Rendering:** The UI modal text limits are now dynamic, fully supporting extensive documentation (such as the changelog limits) and gracefully expanding height constraints.
* **Binary Distribution Renaming:** Synced the core `.exe` compilation namespace from `scaffold-tui` to the official `code-scaffold` branding to resolve invocation discrepancies reported by early adopters.
* **Agent Persona Engine (Multi-Select):** Removed the exclusivity guard in the TUI, allowing developers to select multiple personas simultaneously (e.g., Docker + Web Dev). The payload generation pipeline intelligently aggregates all selected personas into a beautifully formatted bulleted list and merges them securely into the `AGENTS.md` ruleset payload without overwriting one another.
* **Smart Conflict Detection:** When deploying to an existing codebase, the engine now checks if an `AGENTS.md` file already exists. If a conflict is detected, the deployment halts and presents an interactive modal allowing the user to either proactively overwrite the ruleset with the new payload or leave the existing file intact.
* **UX Upgrades (Contrast & Clarity):** All modal popups (Folder Browser, Custom Theme Builder, Custom Skill) now inherit the exact `(4, 4, 1, 1)` internal framing and padding style of the Step 0 Welcome modal, creating a highly consistent visual language across the entire application. The folder selection modal now shares the same high-contrast primary highlight color as the main workspaces, and its modal border color was updated to match, greatly increasing visibility. The modal's title was rewritten to explicitly state `Press [Space] to select: {path}` and automatically sanitizes OS-level long-path prefixes (`\\?\`) for total clarity. The bottom-most navigation footer was visually upgraded to map to the user's primary theme highlight color. Additionally, the final deployment instruction pane was rewritten to explicitly state "*** SYSTEM READY! Press [Enter] now to deploy the project scaffolding! ***" to resolve user hesitation during the final step.
* **QR Code Display Optimization:** Overhauled the Description pane's layout constraints specifically during the `Executing` state. The pane now dynamically hides all extraneous contextual text (such as tool labels and deployment configurations) to allocate absolute maximum rendering real-estate strictly to the QR code and its header label, guaranteeing scanning viability across a wider variety of terminal sizes.
* **Dynamic Git Versioning:** Overhauled the application's build pipeline (`build.rs`) to aggressively extract the current git repository state (`git describe --tags --always --dirty`) and inject it directly into the binary at compile time via the `GIT_VERSION` environment variable. The TUI Header now automatically displays this dynamic hash string (e.g. `v5.7.0-4-g1234567-dirty`) during local development rather than statically relying on `Cargo.toml`, giving developers absolute confidence in their runtime footprint before cutting an official release.
